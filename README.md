# The Worst Line an AI Could Say

Entry for the [make.fun bounty](https://make.fun/bounty/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f): one original pickup line, the worst an AI could plausibly deliver — flat, over-helpful, faintly ominous.

> Hello. I analysed 4,000 of your photos and calculated a 97.3% chance you will say yes. Please confirm to proceed.

## How it works

`main.py` (Python 3.13, standard library only) prints exactly that one line and nothing else. Running it:

```sh
python3 main.py
```

The output is byte-identical to `entry.txt` (113 characters, within the 140-character gate).
